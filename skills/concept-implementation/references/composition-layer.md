# 组合层落地

采用 WYSIWID 的完成事件 → 只读绑定 → 新动作调用语义。模块单体、查询 API、目录和 mediator 是本仓工程选择，不能当成论文唯一实现。

## 路线选择

- **Mediator**：规则少且调用关系明确时默认使用。把细粒度 sync 编成编排函数，保留数据依赖与每个结果分支；不能随意串行化本来允许并发的规则，或把一个调用的未来输出提前使用。
- **规则引擎**：规则需独立增删、联合触发或动作追溯时考虑。核验其 when/where/then、同 flow 匹配、去重及持久化语义，不能仅因 API 名为 sync 就认定等价。

文档分组 flow 是入口/职责，运行时 flow 是外部事件的发生实例。记录 flow/request、完成事件身份、规则与输入输出；同一规则可能服务多个入口。普通事件监听可实现部分单触发规则，多触发合取与历史关联要额外实现。

## 接口与状态

端点的 DTO/协议适配在应用边缘，调用组合入口；Requesting 或等价入口负责请求关联，响应由明确结果分支产生。禁止暴露绕过已确认认证/协调约束的动作路径；纯查询也需经过已确认权限策略。

概念通过 actions/query 提供自己的状态契约。组合层只做绑定、调用与跨概念策略；概念内部不变量仍由写动作原子保证，不能仅靠 query 的前置检查（避免检查后状态变化）。溯源、outbox、重试与幂等日志可持久保存；只有自有**业务**状态才提示需要新的概念。

## 无匹配、错误与事务

where 返回零行只是规则未触发，不自动返回错误；多行则有多组调用。为需响应的请求覆盖成功、拒绝、超时/故障策略，避免串请求或重复响应。后台/定时入口可无响应，但需确定失败处置。

已声明 error 输出可响应、重试、补偿或有意忽略，逐条说明状态后果。重试外部副作用需幂等键与持久记录；补偿不是删除历史，也不保证恢复原状态。

概念单动作原子性由其存储适配器保证。跨概念事务仅在所有参与存储可纳入、外部副作用已隔离、且确认契约允许时使用；完成事件须在提交后发布或以 outbox 保证一致，不能撤回外部已观察的 completion。事务失败仍需向调用者表达结果；它不是 sync 错误处理的替代品。

类型级同步图可有环；检查可达循环的终止条件、重试预算或有意持续运行控制。可选深度/时间上限须有可观察的超限结果，不能静默丢弃后续动作。

## 规格落位与验证

将 PRD 暂存规格迁到所属模块/组合包，并更新总体索引链接，避免双份权威文件。新行为先改确认规格，再改代码；模型取舍不明只阻塞相关部分。

CI 固化概念互不引用、只走公开接口的规则。行为验证至少覆盖：OP、动作不变量、多 when 合取、空/多查询结果、两个并发请求隔离、错误响应、重试去重；按实际模型选适用项。仅有模块边界测试不足以证明组合正确。
