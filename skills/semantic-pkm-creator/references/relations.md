# 八种关系

第二轮「补关系网」读本文。边要能支撑后续组装；每概念 2–6 条。离开对方仍能独立工作 = 参考，不是依赖。

| 类型 | 方向 | 何时用 |
| --- | --- | --- |
| 包含 | 概念→概念 / 实体→实体 | 整体与部分 |
| 依赖 | 概念→概念 | 离开则无法执行 |
| 参考 | 概念→概念 | 仅提及，可独立工作 |
| 调用 | 场景/概念→概念或实体 | 组装或执行时使用 |
| 分解 | 概念→子概念 | 流程性概念的阶段 |
| 父子 | 实体→实体 | 层级，≤3 层；子项须独立来源、独立定义、可被单独引用 |
| 组装 | 场景阶段→概念/实体 | 阶段规则 |
| 别名 | 知识元→名称 | 命名变体，不另立条目 |

判定顺序：先问"离开它还能执行吗"（依赖 vs 参考），再问"是整体的一部分还是阶段"（包含 vs 分解），最后问"谁在用它"（调用 / 组装）。同一对知识元之间只保留一种最强的关系。
