# styles/_template.md — 新增风格的空表

一个风格 = 本文件的一份副本 `styles/<style-id>.md`（kebab-case）+ `assets/<style-id>/` 目录。核心文档只引用变量名，填完即可在 `process.md` 阶段 1 的风格列表里被选中，不改其他文件。

`assets/<style-id>/` 内容：

| 文件 | 必需 | 内容 |
| --- | --- | --- |
| `vars-light.css` | 是 | `:root` 变量块，逐项对照 `deck-format.md` §3 契约 |
| `vars-dark.css` | 否 | 深色 profile，同名变量不同取值 |
| `style.css` | 否 | 风格专属组件 class（前缀 `<xx>-`） |
| `patterns.html` | 否 | 专属页型画廊（外链 core/base.css 与 runtime.js 预览） |
| 图片素材 | 否 | ≤1 MB 合计；商标类不随包分发则写「用户自带」 |

以下六节写进 md：

## 1. 识别特征

一句话：别人一眼认出这是「谁的」胶片靠什么（配色 / 留白 / 字体 / 标志性组件）。写明依据（官方样本 N 份逐页分析 / 公开发布会经验版）。

## 2. 变量说明

不重复贴 CSS；只写：默认 profile 是哪份；强调色取值与来源；`--accent-2` 在本风格里扮演什么；换主色要动哪几项。

## 3. 配色公式

浅色 / 深色各一句「底 + 结构 + 焦点」；强调色允许出现的位置清单；禁止事项。

## 4. 字体与字号档

覆写的字体栈及理由；标题字重与字距；偏好短语卡还是散文（决定 `style-guide.md` §3 档位）；数字大字用色。

## 5. 页型倾向与专属页型

偏好 / 禁用的核心页型（引用 `page-patterns.md` 页型 id）；`style.css` 各组件一句用法；`patterns.html` 各段一句要点。

## 6. 品牌可替换点与素材

| 元素 | 默认 | 位置 | 替换方式 |
| --- | --- | --- | --- |
| 页脚左 | 密级 / 页码 | `.foot-l` | 阶段 1 问，留空只显示页码 |
| 页脚右 | logo | `.foot-r img` | `assets/<style>/…` → data URI |
| 封面背景 | `--bg-cover` | 变量 | 图片 → `url(data:…)` |
| 口号 / 宣言 | 无 | 致谢页 | 文本 |

素材清单：文件、尺寸 / 大小、用途、来源与授权说明。
