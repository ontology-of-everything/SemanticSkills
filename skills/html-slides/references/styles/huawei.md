# styles/huawei.md — 华为官方胶片风格

依据：对 6 份华为官方公开 PPT/PDF（标准空白模板、eKit KV、分销方案、DME 产品胶片、ICT 学院与人才生态胶片、英文存储发布会）共 152 页的逐页分析。
资产：`assets/huawei/`（`vars-light.css`、`vars-dark.css`、`style.css`、`patterns.html`、5 件素材约 1 MB）。

## 1. 识别特征

**白底 + 灰结构 + 红焦点**（浅色，主流）或 **黑底 + 白字 + 金强调 + 红点缀**（深色，产品发布）。红色永远是小面积焦点，从不大面积铺底；标题恒定左上、观点句；页脚三件套（页码 + 密级 / 右下 logo）像素级一致；照片直角，重要图只画红色四角线框。

## 2. 变量说明

- 默认 `vars-light.css`；产品发布 / 技术分享氛围用 `vars-dark.css`。
- 品牌红唯一取值 **`#C7000B`**（官方范围 #C7000B–#CE0E2D，本技能不再用其他红）；两 profile 相同。
- `--accent-2`：浅色为灰蓝 `#566472`（对比 / 旧方案 / 友商）；深色为金 `#E8A33D`——**深色页的信息强调工作色**（卡片小标题、关键词、数字、URL 全用金），红只做品牌锚点（logo、粗箭头、红勾、目录高亮）。
- 不提供「换主色」：换色即不再是华为风格，转用 `generic`。

## 3. 配色公式

**浅色**：红只允许出现在 7 类位置——① 内容页标题（可选；封面与致谢标题一律黑）② 正文关键词红黑混排 ③ 关键数字 ④ 流程 / 阶段标签与箭头 ⑤ 小面积红底白字条幅 ⑥ 装饰线（短下划线、角线、弧线）⑦ CTA。点缀色极少且压低饱和度：矩阵列头可用极浅紫 / 黄 / 蓝区分领域；非华为主体曲线用绿 / 灰。图表：灰阶做底 + 红标强调项；对比表 红点 = 华为、灰点 = 友商。

**深色**：内容页近黑底，深灰卡片靠明度差分区不靠线框；目录页反色成浅灰形成「黑-灰-黑」呼吸；浅色产品截图嵌深色样机作亮块焦点。

## 4. 字体与字号档

- 标题 40–46px 粗体，单行为主，超长自然折两行**不缩字号**；无底色块、无装饰线。浅色 deck 两派：红标题（ICT 系）或黑标题（方案汇报），一份 deck 只选一派。
- 汇报 / 产品胶片走**短语卡档**：正文 4–12 字短语、卡片小标题四到六字断言（「交付成本高」「类型覆盖全」）、关键词**变色不加粗**（一页 3–6 处）。授课保留 21px 散文档。
- 数字必大必变色（浅红 / 深金）+ 黑色小号单位紧贴；偏爱「N+」开区间；数字必挂口径脚注，右下 logo 上方灰色小字「*数据截至：2025 年 8 月」全 deck 统一。
- 高频动词利他式收尾于价值：助力 / 提升 / 使能 / 促进 / 共建 / 打造；记忆口诀可入标题（「1 点 2 线 4 维」「课证共生共长」）；单字前缀章节系统（「课：」「书：」「训：」「赛：」）先一页预告框架，后续每页标题首字回扣。

## 5. 页型倾向与专属页型

偏好：`summary`（TL;DR）、`kpi-band`、`pain-solution-value`、`compare`（AS-IS/TO-BE）、`case`、`matrix`（附录兼容性矩阵）、`quote`。汇报不用 `workshop` / `quiz`。目录页可复用作章节过渡，仅切换红色高亮项。

`style.css` 组件：

| class | 用法 |
| --- | --- |
| `.hw-corner` | 红色四角线框：套在重要图片 / 实证图外层，不描整框 |
| `.hw-bar` | 小面积红底白字条幅（阶段标签、章节横条），永远是小条幅 |
| `.hw-quote` | 大引号引文 + 破折号署名（职务全称），案例页标配 |
| `.hw-conclusion` | 底部结论条：权威引用 + 红数字单行 takeaway（本风格例外允许横贯页底） |
| `.hw-crumb` | 右上三段面包屑：长章节（>8 页）子章节定位，当前段红 |
| `.hw-qr` | 右上二维码位 + 一行用途标签（「课程目录」「报名入口」），与左上标题对角平衡 |
| `.hw-underline` | 目录页「目录」下的红短下划线 |

`patterns.html` 各段：

| 段 | 要点 |
| --- | --- |
| 官方封面 | 全幅 KV + 左上黑标题（`.hw-corner`）+ 底部白条：左「SECURITY LEVEL」右 logo |
| 官方目录 | 黑「目录」+ 红短下划线，纯白底；当前章红 |
| 案例五段式 `case` | 「案例｜对象：做法，价值」标题；左 3：背景条 → 过程三卡 → 成果两数字；右 2：红角框实证图 + 引文署名；页脚三件套 |
| 结论条 + 二维码位 | 内容页可选组件示例 |
| 官方致谢 | 左特大黑字「Thank you.」+ 右栏中英文使命宣言、版权与免责、logo；**无页脚三件套** |

章节页官方版式（未做骨架，需要时按 `chapter` 改）：左图 + 右侧超大浅灰序号顶部出血 + 黑章名 + 灰色子目录（当前小节红）。
