# styles/generic.md — 通用商务（默认兜底）

用户未指明风格时的默认值；也是 `_template.md` 的活范例。资产：`assets/generic/vars-light.css`、`vars-dark.css`；无专属 CSS、无素材。

## 1. 识别特征

无品牌指向的现代商务风：大量留白、深灰文字、一种强调色只做焦点、白卡细边。依据：本仓约定，非任何公司官方样本。

## 2. 变量说明

- 默认 `vars-light.css`；用户要「深色 / 发布会氛围」时整套换 `vars-dark.css`。
- 强调色 `--accent` 深蓝 `#1f4e8c`（浅）/ `#5b9cf6`（深）；`--accent-2` 浅色为冷灰蓝（对比 / 旧方案），深色为琥珀（信息强调工作色）。
- **换主色只改三项**：`--accent`、`--accent-soft`（同色 α .08）、`--table-head`。用户给暖色主色时 `--accent-2` 保持冷灰蓝以维持对比。

## 3. 配色公式

浅色：白底 + 灰阶结构 + 单一强调色焦点。强调色只出现在 eyebrow、关键数字、当前 / 选中卡、流程关键节点、表头。深色：近黑底 + 浅灰字 + 蓝色锚点 + 琥珀作信息强调；大面积强调色不上黑底。

## 4. 字体与字号档

系统字体栈默认；标题 600 字重、`-.02em` 字距。汇报用短语卡档（18px），授课 / 自读用 21px 散文档。数字大字 `--accent`。

## 5. 页型倾向与专属页型

全部核心页型可用，无禁用，无专属页型。

## 6. 品牌可替换点与素材

| 元素 | 默认 | 位置 | 替换方式 |
| --- | --- | --- | --- |
| 页脚左 | 页码 | `.foot-l` | 阶段 1 问密级文字；留空只显示页码 |
| 页脚右 | 无 | `.foot-r img` | 用户自带 logo → data URI，高 28px |
| 封面背景 | `--bg-cover` 纯色 | 变量 | 用户自带图 → `url(data:…)` |
| 致谢页 | 「谢谢」+ 联系方式 | `.thanks` | 文本 |

素材：无随包素材。
