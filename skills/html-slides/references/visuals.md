# visuals.md — 配图工作流：占位 → 落地 → 验收

**字不如表，表不如图。** 讲方法论、方案、原理的页面必须有图或表做主表达。分工：**素材原图给证据**（实验曲线、官方架构图）、**自绘图讲机制**（流程、架构、决策，中文标注、变量配色）、**表格管对比与枚举**。

配图分两段做，**初版不抠图**：初版每个配图位放类型化占位块并登记到逐页表；终版 `grep data-todo` 逐个落地，计数归零后再交付。

## 1. 初版：类型化占位块

类型四选一：**【原图】【自绘·流程】【自绘·架构】【表格】**。占位块带 `data-todo="fig"`（终版按它检索清零），强调色虚线边 + 淡底，两行文字：第一行「类型 + 来源」（mono 14px），第二行「内容一句 + 长宽比」（15px）——规格是给未来的自己或另一个会话看的。骨架见 `assets/core/skeletons.html` 左图右文页内的占位块。

## 2. 落地 A：从素材抽原图

- PDF：用 PyMuPDF 三步——整页渲染找图（像素坐标 ÷ zoom = pt 坐标）→ `zoom 3` 高清裁切 → 目检不满意调 bbox 重裁。裁切**不含**原图注，中文图注自己写并标「论文 Fig N」。
- PPTX：`zipfile` 解包 `ppt/media/` 直接取原图；或 `soffice --headless --convert-to pdf` 后走 PDF 流程。
- 素材 >3 篇时并行派 agent，每个给足：文件绝对路径、目标图描述、输出文件名、上述方法，回复一行 JSON（file / figure / 内容 / 宽×高）。
- 嵌入：base64 → data URI（`deck-format.md` §3）。图卡片统一：图 `width:100%;object-fit:contain;flex:1;min-height:0` + 13px 图注居中。

## 3. 落地 B：自绘流程图 / 架构图

用 div + flex 或 inline SVG 拼装，不用画图工具。节点默认 `--surface` 底 `--line` 边；`--accent` 只给关键节点 / 瓶颈 / 当前路径。三种常用拓扑（外层套一张 `.card`）：

- **直线流程**：节点 → 节点 → 节点，瓶颈标 `hot`（管线、漏斗）
- **分支流程**：输入 → 判定，↓，两个并排分支，↓，汇合（决策逻辑）
- **多路对照（泳道）**：共享头部行，每路一行「↳ 方法 → 结果大数字」，胜者行标红（评测对比）

选型：机制 / 流程 / 决策 → 自绘；实验证据 / 复杂官方架构 → 抽原图；两者可同页共存（自绘讲「怎么转」，原图证「真的行」）。

**异构架构必须展开差异单元**：不同层 / 模块执行路径不同时，不能只画「L0 / L1 / L2」方框列表；以源码、配置、正式规格为事实源，至少展开两个代表单元，从输入画到输出（`input → operator → state → selection → normalize → cache/output`），标清哪个单元多了状态、缓存或通信步骤。省略中间步骤要用明确省略号。

**架构图视觉规范**：箭头从节点边缘出发、终止在目标边缘，不穿字、不悬空、不反向；多条分支分别画 path；图内文字短句化，长解释移到图外；不通过把字号压到不可读来硬塞；**禁止用红框把普通区域圈一遍**。

## 4. 落地 C：标准表格

对比、枚举、速查统一用这套，不自行发明配色（骨架在 `assets/core/skeletons.html`「标准表格」段）：

- 表头 `--table-head` 底 + 白色 15px 粗体居中，高 46px
- 表体 15px `--fg`，网格 1px 黑线；分组用 `rowspan`，分组范围 3px 黑粗外框
- 三列默认 `15% / 19% / 66%`，宽度写到每个 `th` / `td`，不只靠 `colgroup`
- 文字优先单行，放不下自然换行（`white-space:normal;overflow-wrap:break-word`），**禁止 `nowrap` 裁切**
- 表格 `flex:1;min-height:0` 吃满主体，不再写 `height:100%`（标题高度会被重复计入）

单元格文字是图元，15px 不受散文地板约束；空间充足可升 17px。标准行高约 38–44px，超过 ~18 行拆列或拆页。

## 5. 验收与踩坑

- 每落地一批：`grep -c data-todo` 递减到 0；`?debug` 无红框；改动页截图目检（图不糊、不裁、图注完整）。
- **SVG 文字不会触发溢出检测**：每张自绘 SVG 必须截图放大目检——文字越框、箭头方向、线条是否接在框边、公式下标是否缺字（Noto Sans SC 无 ₁₂ 下标字符，用 `<sub>`）。
- 架构图至少两轮截图：第一轮查结构与层级，第二轮查边界、线条、颜色。
- 图注必须写出处；数字型结论进 `.num` 或表格，不埋在图注里。
- 自绘图去花花绿绿：只用 `--accent` / `--accent-2` / 中性灰；素材原图保留原色。

| 错误 | 纠正 |
| --- | --- |
| 初版直接抠图画图 | 只放类型化占位块 |
| 占位块只写「图·占位」 | 类型 + 来源 / 内容 + 比例两行 |
| 裁图带原图注 | 裁掉，自写中文图注标「Fig N」 |
| 抽象层列表代替异构结构 | 依源码展开代表单元与差异分支 |
| 普通区域全画红框 | 中性灰边，红只给关键差异 |
| SVG「差一点」对齐 | 放映会明显越框；逐项目检校正 |
| 落地后不清点 | `data-todo` 归零再交付 |
